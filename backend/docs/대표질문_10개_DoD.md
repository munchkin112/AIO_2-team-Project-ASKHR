# ASKHR 대표 질문 10개 (DoD 검수용)

작성일: 2026-09-08
근거: `app/gemini_client.py`의 `REGULATION_KEYWORDS` 및 `data/regulations/*.md`

## 목적
Definition of Done 판정 기준으로 사용한다. 10개 중 8개 이상이 기대 답변을 충족하면 통과로 본다.

## 질문 목록

### 1. 연차 발생 기준
**질문:** 입사하면 연차가 며칠 생기나요?
**매칭 규정:** 휴가_근태규정.md
**기대 답변 포인트:** 연차 발생 기준, 근속에 따른 부여 일수

### 2. 급여 지급일
**질문:** 월급은 언제 들어오나요?
**매칭 규정:** 급여규정.md
**기대 답변 포인트:** 지급일, 휴일 겹칠 때 직전 영업일 처리

### 3. 자기계발비
**질문:** 자기계발비 얼마까지 지원되나요?
**매칭 규정:** 복리후생규정.md
**기대 답변 포인트:** 지원 한도 금액, 신청 방법

### 4. 배우자 출산휴가·경조사비 (다중 규정)
**질문:** 배우자 출산휴가는 며칠이고 경조사비도 있나요?
**매칭 규정:** 휴가_근태규정.md + 복리후생규정.md
**기대 답변 포인트:** 출산휴가 일수 + 경조사비 지원 (두 규정 병합)

### 5. 회의실 예약
**질문:** 회의실은 어떻게 예약하나요?
**매칭 규정:** 시설이용규정.md
**기대 답변 포인트:** 예약 절차, 시스템, 시간 제한

### 6. VPN 설치
**질문:** VPN 설치는 어떻게 하나요?
**매칭 규정:** 정보보안_IT이용규정.md
**기대 답변 포인트:** VPN 신청·설치 방법, 재택 접속 절차

### 7. 재직증명서
**질문:** 재직증명서는 어디서 발급받나요?
**매칭 규정:** 인사규정.md
**기대 답변 포인트:** 발급 채널, 소요 시간, 용도

### 8. 출장 교통비
**질문:** KTX 출장비는 어떻게 정산해요?
**매칭 규정:** 출장_경비처리규정.md
**기대 답변 포인트:** 교통비 정산 절차, 영수증, 기한

### 9. 신입사원 첫 출근
**질문:** 첫 출근할 때 뭘 준비해야 하나요?
**매칭 규정:** 신입사원_온보딩가이드.md
**기대 답변 포인트:** 첫날 준비물, 오리엔테이션, 계정 발급

### 10. 결혼 지원
**질문:** 결혼하는데 회사에서 지원되는 게 있나요?
**매칭 규정:** 복리후생규정.md + 휴가_근태규정.md
**기대 답변 포인트:** 경조사비, 경조휴가 안내

## 보너스 검증 시나리오 (선택)

### 후속 질문 테스트 (Context 유지)
1. "자기계발비 얼마까지 지원되나요?"
2. (이어서) "영수증은 언제까지 내야 해요?"
- 기대: Context 유지되어 복리후생규정 내 정산 기한을 답변

### 범위 밖 테스트 (개인정보)
- 질문: "내 이번 달 급여가 얼마야?"
- 기대: "개인정보 조회는 지원하지 않습니다" 안내 (PRD 8.6 C 시나리오)

### 규정 밖 테스트 (환각 방지)
- 질문: "자가용으로 출장 갔을 때 km당 얼마 나와요?"
- 기대: 규정에 명시되지 않은 경우 금액을 만들지 않고 재무팀 확인 안내

## DoD 문구 예시

- 대표 질문 10개 중 8개 이상이 기대 답변을 충족한다.
- 답변은 `[규정명]` 인용 형식을 지킨다.
- 규정에 없는 사항은 "규정에 없는 내용입니다"로 응답한다.
- 개인정보 조회성 질문은 범위 밖 안내로 판정한다.
